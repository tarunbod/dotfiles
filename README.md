# dotfiles

My nix-based dotfiles setup for macOS and linux.

## Installation

macOS:

```zsh
xcode-select --install
git clone https://github.com/tarunbod/dotfiles.git
~/dotfiles/init.sh
```

ubuntu:

```bash
sudo apt install git xz-utils
git clone https://github.com/tarunbod/dotfiles.git
~/dotfiles/init.sh
```
